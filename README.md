# 集集．慢車上的百年小鎮（課程示範網站）

數位人文地方策展專題實作｜教師示範網站

網站網址：https://kuoyuliu.github.io/jiji-demo-site/ 

這是一個**完整的線上策展網站範例**，用來在課堂上解說：一個策展網站從內容、圖片授權、版面設計到互動元件，可以做到什麼程度，以及它是怎麼組成的。

## 站圖

```
index.html          首頁（主視覺、小檔案、四展區入口、三次重生、行程 CTA）
├── railway.html    展區一：集集車站與集集線（集集線路線圖、百年時光軸）
├── street.html     展區二：站前老街與山蕉（散步地圖）
├── wuchang.html    展區三：武昌宮與九二一（震災前後對照滑桿）
├── mingxin.html    展區四：明新書院
├── plan.html       行程規劃（路線分頁、加入行事曆、散步地圖、集章任務、FAQ）
├── about.html      策展理念與 AI 聲明
└── sources.html    參考資料、圖片授權、查證筆記
```

## 課堂解說重點：行銷設計的六個手法

| 手法 | 在哪裡看 | 說明 |
|---|---|---|
| 一句話主張 | 首頁主視覺「搭一班慢車，走進一百年。」 | 3 秒內讓訪客知道這裡是什麼、為什麼要看 |
| 主要與次要行動按鈕 | 首頁「開始參觀」「規劃我的集集行」、導覽列「規劃行程」 | 每一頁都告訴訪客下一步可以做什麼 |
| 用數字建立可信度 | 首頁小檔案（1922、7 站、4.5 公里、1885） | 數字比形容詞更有說服力，且每個數字都有出處 |
| 時事鉤子 | 頁首公告「集集線 2026/6/25 全線復駛」 | 給訪客「現在就去」的理由 |
| 從線上到線下 | 行程規劃頁、加入行事曆、集章任務 | 把「看完」變成「出發」 |
| 分享與社群預覽 | 分享按鈕、每頁的 og 標籤 | 讓訪客幫你宣傳 |

## 互動元件與對應程式

所有互動都寫在 `js/main.js`，依編號分段；樣式在 `css/style.css` 的第 7、8 段。

| 元件 | 頁面 | js/main.js 段落 | 想修改內容時 |
|---|---|---|---|
| 捲動進場、數字跳動 | 全站 | 第 2 段 | 在元素加上 `class="reveal"` 或 `data-count="數字"` |
| 集集線路線圖 | railway.html | 第 3 段 | 改 railway.html 按鈕上的 `data-text` |
| 百年時光軸 | railway.html | 第 4 段 | 在 `EVENTS` 陣列加一行 |
| 震災前後對照 | wuchang.html | 第 5 段 | 換掉兩張 `<img>` |
| 散步地圖 | street.html、plan.html | 第 6 段 | 地點資料在 build 時寫入頁面的 `map-data` |
| 行程分頁、加入行事曆 | plan.html | 第 7 段 | 改 plan.html 的 `<ol class="route">` |
| 線上集章 | plan.html | 第 8 段 | 增減 `.stamp` 按鈕 |

## 品牌設計

- 配色（`css/style.css` 第 0 段）：檜木 `#b06a32`、山蕉黃 `#f3c449`、樟樹綠 `#1f4a3a`、和紙 `#faf6ee`、墨色 `#262320`。
- 字型：標題 Noto Serif TC（襯線，有人文感）、內文 Noto Sans TC（易讀），由 Google Fonts 載入。
- 每一個顏色都來自集集本身：檜木車站、山蕉、綠色隧道的樟樹。

## 使用規則（和學生的網站一樣）

1. 純 HTML、CSS、原生 JavaScript，不用框架。
2. 連結與圖片一律使用相對路徑。
3. 每張圖片都有 alt 替代文字，出處寫在 `sources.html`。
4. 支援手機版、鍵盤操作與「減少動態效果」設定。
5. `.devcontainer/`、`.github/` 請勿刪除；推到 GitHub 後在 Settings → Pages 選 GitHub Actions 即可發布。

## 發布後要做的一件事

把每一頁 `<head>` 裡 `og:image` 的相對路徑改成完整網址，社群分享時才會出現預覽圖。
